# Contributing

We welcome reproducible bugs, docs improvements, adapter proposals, accessibility improvements and tests. Please open an issue before significant architectural changes. Use `npm test && npm run check`. Preserve the local-first, R0-spend default. Never commit secrets, company client data, private characters/assets or training data you do not have the rights to distribute. New adapters must declare actual supported upstream capabilities and fail closed when they are missing. Pull requests require human review and documented verification. Be respectful and inclusive.
