# Security policy

This is a pre-release, local-only prototype. Do not expose the dev server to the internet or embed the scene renderer in a production service. Do not submit security vulnerabilities as public issues. Contact the maintainers through the GitHub repository's private security advisories when enabled, or request private contact details without revealing exploit information. No active bug bounty. Scene import via file is not supported in this alpha. The parser limits dimensions and item counts. Avoid running exported CAD Python from untrusted sources without inspecting it.
