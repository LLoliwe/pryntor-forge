# PRYNTOR WORLDWEAVER R1 (PRIVATE)

An original, local-first deterministic playable-world research prototype. Built on WORLDWEAVER R0, without copying source from img2pixi2d or overwriting the founder-liked ZOWIBO Glow Garden / SPARK! checkpoint. This prototype is NOT official ZOWIBO character art, automatic image segmentation, an educator-certified learning product, public children’s game or commercial release.

## Ways to play

- **Single HTML:** Open `WORLDWEAVER_R1_PRIVATE_OFFLINE.html` in a browser that permits local scripts. No dependencies, API calls or accounts. Some mobile file preview apps disable scripts: if the viewer shows a blank scene, use a regular browser or the Node server. A private hosted preview still requires separate owner, IP and security review.
- **Local server:** Run `npm start` using Node.js 20+ and open `http://127.0.0.1:4173/worldweaver`.
- **Keyboard and touch:** A/D or arrows to move, Space/W/up to jump. Tap mobile controls. Hold jump for more height, tap for a shorter jump. Pause and restart are available.

## What R1 adds over R0

1. **Tuned real play:** momentum/acceleration, jump height modulation, coyote forgiveness, buffered jumps, horizontal solid collisions, ceiling collisions, checkpoint saves and recoverable failures.
2. **Playable creator tools:** add platforms, collectibles, hazards or checkpoints; erase safely, save scene JSON and reimport validated scenes. No image is embedded or auto-segmented.
3. **Deterministic evidence:** fixed-step simulation, replay inputs and structured event summaries, physics checks, adversarial invalid-geometry/collision tests, 17 core unit tests.
4. **A strictly separate educational micro-lab:** Battery + Wire + Switch controls follow the 8-case truth table. Light turns on only when all three conditions hold. The model uses an idealized complete circuit and needs qualified educator/child-age review.
5. **Accessible local-first interaction:** touch and keyboard, 44px targets, focus styles, reduced-motion visuals, text explanations, privacy by default, rights-gated reference image background.

## Not in R1

- Automatic object segmentation, alpha mattes, inpainting, character rigs, art fidelity recognition, AI agent semantic extraction, full 3D rendering, game monetization, creator uploads or direct deployment into ZOWIBO, LVL7 or RELICBOUND.
- Physical iPhone/Safari user test, child-directed safeguarding legal review, premium film animation, full audio/licensed track, independent artistic/educator signoff or commercial success.
